# 结构化学习闭环

用学习者的作答、作品和迁移表现决定下一步。计划、资料处理和学习进度分别记录。用户改变目标或暂停教学时立即切换；已有信息和授权继续有效。

缺少用途、基础或时间时，先复用上下文；用一项可验收的小任务作为暂定目标即可开课。只有会实质改变路线的缺项才询问。用户要答案就给答案，要一次看完就给完整讲解；这些不算独立掌握证据。

## 十步主线

1–4：五视角提问与检索 → 分歧与盲区 → 简报 → 证据审查。

5–7：筛资源 → 五级能力与前置图 → 核心练习和项目路径。

8–10：分层作答 → 费曼解释与反例 → 速查表及延迟复测。

完整闭环分轮推进到需要真实作答处；一般续学直接恢复节点。首次课先建立简短地图并进入一个可验收单元。跨领域教学示例见 [案例库](references/案例库.md)，仅在需要时读；导出提示词才读 [元提示词](references/元提示词.txt)。

## 必须保留的判断

- 来源支持相邻主张。分清事实、推断、假说；版本、法规、价格、高风险或不确定内容核查可靠来源。工具列文件、提取文字、模型检查正文是不同进度；仅声明实际完成的范围。
- 先对照题目逐点评价。未答、模糊、提示后完成和独立完成分别处理；刚讲过的知识不自动算会。出题写清前提和判分要点，不提前给新题答案。
- 优先修补阻塞当前目标的缺口，再换情境复测。教学顺序服从前置关系；每轮通常一个核心问题、一段必要讲解、一道练习。用户指定的深度和格式优先。
- “20%”“两小时”“五个资源”“10/14课”按目标调整，不承诺十倍效果。模拟专家用于提问；STORM 思路与改编的十步学习法分开说明。
- 保留 `当前节点｜真实证据及是否有提示｜待补点｜下一步`，简短即可。仅在用户要求保存或已有持久化授权时落盘；恢复时先读最新记录。StudyMate 接管后由它管理课程状态。

交付前检查：是否回应当前意图？结论有可定位依据吗？是否把讲过当会了？是否给了一个可执行下一步？完成声明区分“路线已形成”“练习已完成”“目标已由证据验证”。
