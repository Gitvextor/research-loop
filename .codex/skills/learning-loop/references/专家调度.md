# 专家调度与合成

用于单专家、快扫、完整五视角建图及简报审查。五个视角是分析框架；证据审查员不冒充真实教授或正式同行评审。

## 选择运行成本

| 请求 | 运行方式 | 交付 |
|---|---|---|
| 普通授课、批改、续学 | 教练直接处理 | 一个可验证的学习动作 |
| 指定单专家 | 只读并运行该角色 | 该视角结论与证据 |
| 快速了解或时间很短 | 单助手用五个视角各提关键问题 | 紧凑地图，标“单助手多视角” |
| 明确要求专家分别运行，或完整建图 | 可用时并行五位，再做综合审查 | 各方发现、分歧、核查后的简报 |
| 仅审查简报 | 只运行审查员 | 证据缺口与修订 |

本规范允许在完整建图或明确的专家组请求中分派子代理。工具不支持独立上下文时，按视角分段分析并说明；不称作独立专家会审。用户指定全部角色时保留全部，不以省成本为由省略。

## 角色入口

| 目的 | 独立设定 | 项目子代理名 |
|---|---|---|
| 工作流、实操与故障 | [实践者](experts/实践者.md) | `learning_practitioner` |
| 机制、研究与证据 | [学者](experts/学者.md) | `learning_researcher` |
| 失败、反例与风险 | [怀疑者](experts/怀疑者.md) | `learning_skeptic` |
| 投入、收益与责任 | [经济学家](experts/经济学家.md) | `learning_economist` |
| 演变、制度与路径依赖 | [历史学家](experts/历史学家.md) | `learning_historian` |
| 审查主张与来源匹配 | [证据审查员](experts/证据审查员.md) | `learning_peer_reviewer` |

只加载本轮选中的角色设定。宿主支持命名子代理就用表中入口；仅有通用子代理时传入相应 MD 的绝对路径和相同任务简报，不依赖未确认的注册能力。

## 共同输入与证据

分派包：`主题/目标｜基础及已知证据｜地域/时点｜预算与本轮范围｜角色MD绝对路径｜原始材料定位｜已知缺口`。可以共享同一组原始来源，不给其他角色的预设结论。每位只补检索自己缺失的信息，避免五次重读整套资料。

每位通常交付 1–3 个高影响发现，采用：
`主张｜事实/推断/假设｜来源URL或文件+页码｜适用条件｜不确定性｜对学习顺序/验证任务的影响`。
另给一个能改变判断的反例、跨视角问题或最低成本验证。够用即可，不为凑数加问题。角色专属产物仅在能帮助当前目标时展开。

检索变更中的事实或证据缺口。检索不足就保留未知，不用角色身份提高可信度。多个角色引用同一来源只算一份证据；即使分别运行也不保证来源独立。

## 合成与审查

1. 按议题去重，保留支持和反对的来源。用 `议题｜一致点｜冲突主张｜定义/范围/事实/价值分歧｜未查问题｜验证` 整理。没有实质分歧就直说，不安排表演式争论。
2. 按对目标的影响排序，默认保留最多五条关键发现及一项下一步验证；关联是推断就注明。快扫可一次合成结束；完整建图再把原始产出、关键简报和证据交给审查员。
3. 审查优先处理改变路线的结论，逐条给支持、部分支持、不支持或未核查。修订受影响主张，保留未决异议。只有新证据或明确未解决问题才再开一轮，禁止无终止条件的互评。
4. 任一角色失败时报告缺失角色，按已得证据交付部分地图，不能宣布全组完成。真正完成后收集结果并关闭不再需要的子代理。
5. 用修订简报进入资源与路径设计；需要 StudyMate 时填 [交接模板](../assets/StudyMate交接模板.md)。调研阶段成果不能写成学习者已掌握。

默认在已有证据足以支持本轮的可逆下一步时结束检索；会改变路线的重大未知必须保留。不要用“十倍速”替代成本和掌握证据。
