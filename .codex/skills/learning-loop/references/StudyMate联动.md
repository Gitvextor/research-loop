# StudyMate 联动协议

本协议只在用户明确要求两套流程联动时加载。分工：`learning-loop` 做证据支撑的五视角领域地图与路线建议；StudyMate `learning-system` 管正式课程、HTML 课件、练习、评估和持久进度。双方都可提建议，StudyMate 学习工作区是课程状态的唯一事实来源。

## 入口和可用性

用户可直接说：`$learning-loop-studymate 我想学 Python 自动化，先做五视角调研，再交给 StudyMate 建课。` 已在本技能内的用户也可说“接入 StudyMate”。

先查当前环境是否有 StudyMate 完整插件的 `learning-system`，以及用户指定或已有的学习工作区。当前仓库有本地源码 `Study-Mate-main/Study-Mate-main`；源码只是开发材料。Codex 插件的标准使用入口见其中 `docs/Codex与ChatGPT.md`：导入完整 `studymate-openai.zip`，新任务选择 `$learning-system`。构建出的插件才包含 `skills/`、`scripts/`、`templates/`、`schemas/`；不要只复制一个角色文件或把 `.dsh` 的安装指令当 Codex 启动指令。

如果插件已可用，在同一任务允许读取其技能文件时，读取实际安装的 `learning-system/SKILL.md`，按它的宿主约定执行；若宿主需新任务选择技能，交付下方的可复制交接指令。仅有源码时仍可完成研究简报与交接文件，但必须标记“StudyMate 尚未接管”，不可声称已生成课件或进度。

学习工作区沿用用户已经指定的位置，或按 StudyMate 已安装版本的定位规则恢复。源码根、插件缓存、示例目录都不是用户学习工作区。已有科目先只读恢复并辨认目标是否一致，不创建同名新课。没有工作区路径时可先做调研或在回复中给出简报；到需要持久化时再确定位置。

## 新课：从调研到建课

1. 复用已有简报、来源和学习证据，只补会改变目标路线的缺项。没有简报且请求完整调研时，`learning-loop` 完成步骤 1–4，并给步骤 5–7 的候选建议。使用 [交接模板](../assets/StudyMate交接模板.md) 传递信息；每条事实附来源与实际检查范围，基础和兴趣等标为“用户自述”，未做的步骤、未选项目和未答诊断明确标记。
2. 将 `目标与成功标准` 对应 StudyMate 的 `MISSION.md`；`限制/前置` 对应建课盘问；`可靠资源与缺口` 对应 `RESOURCES.md` 的入口；`核心节点/前置图` 交给 `curriculum-designer` 作建议；`验证任务与错因` 交给 `practice-evaluator` 作出题依据。StudyMate 自己决定正式节点、课型和文件结构；外部简报不直接冒充它的 `curriculum.yaml`、`progress.yaml` 或评估记录。
3. 将简报路径或正文连同绝对学习工作区交给 `$learning-system`：

   `请按 StudyMate 的 learning-system 流程接入这份外部学习简报：【交接文件绝对路径】。已知信息请复用，只问缺失且会影响建课的选择。先核对我的已有科目与进度，再把调研结论当作有来源的候选输入；项目、实验载体和正式课程按 StudyMate 规则确定。学习工作区：【绝对路径】。` 

4. 区分交接状态：简报已准备（有正文/文件）、StudyMate 已读取（有实际接收响应）、待用户选择（有具体待选项）、已建课（有课程文件）、已开始首课（有实际课件或教学）。回执应含工作区、科目、当前节点、产物位置和下一步；未发生的状态不能提前填写。待选问题不等于已建课。

## 续学与回流复盘

- 用户说“用 StudyMate 继续”：先读取其真实 `interaction.json`、科目目标、课程大纲、进度与最近评估；按 StudyMate 总控恢复当前节点。若插件不可用，给出准确的启动指令与现有简报，不假装续学。
- 用户说“用十步闭环复盘 StudyMate”：只读现有 `MISSION.md`、`RESOURCES.md`、`curriculum.yaml`、`progress.yaml`、最近的 `assessments/`、学习记录与误解记录。提炼目标、已验证能力、反复错因、资源缺口，做针对性步骤 8–10 或补充步骤 1–4。外部复盘以建议形式返回：`对应节点｜证据｜建议补练/更正｜待核查来源`，由 StudyMate 总控按其规则改档案。
- 若两边判断冲突，优先展示各自证据和时间；StudyMate 的真实作答、运行结果、评估记录比外部学习计划更能证明掌握度。不要从一条聊天自述推高 mastery，不覆盖已有用户作品。

## 范围与异常

StudyMate 初始定位偏重数学与计算机；别的主题可以先做研究简报，但正式课程是否支持由实际插件能力与用户目标决定。插件不在当前环境、依赖缺失、工作区只读或链接失效时保留简报与状态，报告具体缺口及可执行入口。不要为联动擅自安装插件、改全局配置或把学习数据写进上游源码。
