# 教学与评估方法

依据真实作答调整下一轮。普通答题反馈无需重跑五视角、重新制订整门课或打开无关资料。

## 一轮教学的最小闭环

1. **定位**：恢复当前问题、前提和验收点；没有基础证据时用一个小诊断，或先给完整示范。
2. **判断**：逐点对应学习者实际表达，区分正确、错误、缺失、歧义。只引用对方说过的内容。“可能有冲突”“大概差不多”不足以证明机制正确。
3. **反馈**：给出正确部分、一个最影响理解的缺口、简短因果解释或对照例。若前次讲解错误或过度绝对，先明确修正自己的表述。
4. **验证**：换数据、条件或例子，给一道能定位剩余缺口的题，并等待真实作答。判分要点描述能力与理由，不泄露这道题的答案。

用户索要完整答案就直接给；要求“先别出题”时到讲解结束，不附新的作答要求。未收到回答不能替用户答题、完成费曼复述或宣布考核通过。

## 自适应讲法

| 作答表现 | 下一动作 | 验证方式 |
|---|---|---|
| 不懂它解决什么 | 从具体麻烦讲起，介绍必要术语 | 判断何时需要它 |
| 概念混淆或只背定义 | 一组正反例，说明区别来自哪个条件 | 改一处条件后预测结果 |
| 步骤卡住、开始猜测 | 分解任务；完整示范后逐步减少提示 | 独立完成剩下的一小步 |
| 答案正确但理由缺失 | 追问关键因果，不立即升难度 | 一句话解释或提供反例 |
| 正确且理由充分 | 减少重复示范，加入迁移或排错 | 新场景完成并核对结果 |
| 自述太简单、太难 | 调整题目负担，以新作答定位 | 不用自述直接升级或降级 |

讲解采用“具体例子 → 机制 → 适用条件”，需要时配图。类比要点出边界；不能省略关键条件而制造错误规则。不要用尚未教过的工具语法判断目标概念是否会了；先介绍语法或换不依赖它的题。每轮通常只补一个阻塞缺口，不连续引入一串新术语。

## 掌握度只随证据更新

| 观察证据 | 可记录的状态 |
|---|---|
| 未答、仅说懂了、回答不能判定 | 待验证 |
| 刚获得解释或依靠明显提示答对 | 已讲解／有提示完成，待独立验证 |
| 独立解释或完成熟悉题且理由正确 | 初步理解 |
| 新情境独立完成目标任务并解释边界 | 能独立应用 |
| 延迟回测失误 | 需要复习；保留以前的成功证据 |
| 项目达到事先约定的标准 | 项目验证；仅针对覆盖节点 |

多问题回答逐项记录，答对一个不代表其余正确。选对答案但推理错误要标出；不要用总分掩盖前置缺口。记录 `节点｜题目/产物｜实际表现｜独立/有提示｜状态｜待补点`，不用没有量表依据的掌握百分比。

## 复习与状态

优先复测有明确错因、前置作用大或已遗忘的节点。下次会话用一道短题恢复，不重新铺全套地图。两种方法分别学过后再混合练习，以检验何时选哪种。复述要求解释用途、机制与边界，可用正反例；能讲顺仍需迁移任务。

日常回复末尾用一行 `当前节点｜证据/缺口｜下一步` 即可。有保存授权时在指定工作区记录题目、作答和是否有提示；StudyMate 课程复用其档案。只建议复习时机不等于设置了定时提醒。

研究依据供进一步核对：[Roediger 与 Karpicke，2006](https://pubmed.ncbi.nlm.nih.gov/16507066/)；[Dunlosky 等，2013](https://pubmed.ncbi.nlm.nih.gov/26173288/)。不把这些研究换算成个人固定提速倍数。
