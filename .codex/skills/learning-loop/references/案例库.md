# 案例库：把同一闭环迁移到不同主题

以下是教学设计示例，不是对行业事实的断言。使用时替换目标、资料和验收条件；不要把示例项目当用户已经选择的项目。

## 案例 A：零基础学习 Python 自动化

- 目标：两周内独立写出一个整理下载文件的脚本；交付脚本、测试样例及运行说明。
- 五视角：实践者问“路径、重复文件、误删如何处理”；研究者问“文件系统与异常机制是什么”；怀疑者问“遇到同名文件或中途失败会怎样”；成本视角问“自动化是否值得维护”；历史/制度视角问“不同操作系统与权限约束”。
- 分歧：先做功能还是先处理安全边界？用“小样本演练 + 干运行模式 + 可回退动作”验证，不靠辩论拍板。
- 核心：变量与分支、遍历文件、路径处理、异常和测试。资源从当前 Python 官方文档与一份可练习入门材料中挑；具体 API 使用前核对文档。
- 两小时冲刺：看一段读取目录的示范 → 自己筛选文件类型 → 预测同名文件结果 → 在测试目录运行 → 记录一个真实报错。
- 项目里程碑：列出计划动作、在测试目录整理、处理同名与失败、写测试和使用说明。考试依次问“为什么先预览”“改规则会怎样”“给一个误删场景如何排查”“如何交付给另一台电脑使用”。
- 费曼检查：“向 12 岁学生解释什么是路径，以及为什么脚本不能直接在唯一的原始文件夹试跑。”速查表留下运行步骤、常见异常和回退方法。

## 案例 B：学习线性代数中的矩阵乘法

- 目标：能解释矩阵乘法何时有定义、完成计算，并用它描述一次坐标变换。
- 五视角可重排为解题者、数学家、怀疑者、计算者、应用者：分别看算法、定义、反例、计算代价与真实模型。
- 分歧：“按行列机械计算”与“理解线性变换合成”哪个先学？先用二维图像或具体数值建立直觉，再用定义检查形状与运算；两条解释应指向同一个结果。
- 核心：维度匹配、行列点积、变换合成、单位矩阵和顺序不交换的例子。资源可选可靠教材章节和有练习的课程，不必凑五个。
- 两小时冲刺：两个 2×2 例子 → 改一个矩阵观察输出 → 找出维度不匹配的错误 → 在图形或数据上应用。
- 验收题：先预测结果的形状，再计算；给错误解法找根因；设计两个矩阵展示顺序差异。费曼检查：“为什么 A×B 和 B×A 不能随便交换？”速查表留维度规则、计算模式和常见错法。

## 案例 C：练习英语面试回答

- 目标：在目标岗位的模拟面试中，能用两分钟讲清一段项目经历，并回答一次追问。
- 五视角可改为面试官、候选人、语言教师、怀疑者、行业实践者。实践者看岗位相关性，语言教师看可懂度，怀疑者追问事实与量化成果，成本视角可改为准备时间与机会成本。
- 争议：背模板能保证流利，却可能在追问时失灵。验证方法是保留经历事实、尝试不同提问顺序、录音后比较答复是否自然且一致。
- 核心：结构化讲经历、连接词、常见追问、澄清问题、简明表达。资源应包括目标岗位描述和可核对的语言材料；避免用模板掩盖经历细节。
- 练习：先看一段示范 → 用自己的经历改写 → 录音 → 根据“清楚、真实、切题、回应追问”四项反馈再录。L3 练习为发现自相矛盾或模糊句；L4 为完整模拟面试。
- 费曼检查：“用日常语言解释你在项目中真正做了什么。”速查表只留经历要点和提醒词，不写逐字稿。

## 案例 D：研究自动驾驶议题

- 目标：写一页有来源的议题简报，能说明技术、验证、成本和治理之间的关系；不预设最终结论。
- 五视角沿用实践者、研究者、怀疑者、经济学家、制度/历史观察者。每方先提出问题，再根据当期公开资料回答；对特定公司、安全率、法规和成本的主张必须重新核查日期与适用地区。
- 矛盾图谱示例：不同参与者对“安全”定义、比较基线和可接受风险可能不同。把它拆成可测量指标、数据来源、未报告情境与责任分配，而非让模拟角色争胜。
- 核心学习：系统边界、评价指标、长尾场景、失效分析、责任框架。两小时冲刺是阅读两份不同类型的一手材料，做主张—证据表，再为一个场景设计验证问题。
- 测验：指出一项统计比较缺少的基线；解释一个看似强的案例为何仍不足以证明普遍安全；为新城市部署提出三项待核查条件。速查表保留指标定义、关键来源和未解问题。

## 七种快扫场景

| 场景 | 五视角后应留下的最小产物 |
|---|---|
| 写文章/报告 | 读者关心的问题、争议、可核查来源和文章论点 |
| 重大商业决策 | 方案、代价、失败模式、反证条件和下一次验证 |
| 求职面试 | 岗位需求、公司公开事实、竞争态势、待向面试官确认的问题 |
| 投资学习 | 历史情境、假设、风险与数据来源；具体投资判断另做高标准核查 |
| 学新技术 | 领域地图、前置知识、关键教程、最小可运行任务 |
| 谈判准备 | 双方利益与约束、可让步项、验证对方假设的问题 |
| 演讲准备 | 听众已有认识、最可能异议、证据、可回答的边界 |

快扫只产决策或学习入口；需要长期掌握时再进入课程、测验与讲解循环。
