# research-loop

一个面向系统学习的本地工作区，融合多视角研究、核心路径、检索练习、费曼讲解和复测反馈。

## 内容

- `.codex/skills/learning-loop`：十步学习闭环 skill、元提示词、专家角色和 StudyMate 交接协议
- `.codex/agents`：实践者、学者、怀疑者、经济学家、历史学家及证据审查员入口
- `Study-Mate-main`：StudyMate 源码与联动材料
- `操作系统`：操作系统教材、课件、作业和课堂检测资料
- `evaluations`：学习评估记录

## 快速开始

在 Codex 中使用 `$learning-loop` 开始学习；需要单独运行专家时，参考根目录的 `学习闭环-专家Agent入口.txt`。

操作系统学习资料的入口在 `操作系统/操作系统/`。
