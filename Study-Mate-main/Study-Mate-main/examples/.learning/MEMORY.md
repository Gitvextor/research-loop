# 学习者记忆

> 跨科目、跨会话的共享记忆。按下面的分节增补与修正，不做整篇重写。

## 我是谁

- 现有技能：Python 能写小脚本（读写文件、跑循环、装包）；C 语言上过一学期，指针现在生疏
- 各领域当前水平：
  - 数学：微积分学过、能用；线性代数零基础，只会解二元一次方程组
  - 计算机网络：会连 WiFi、会用浏览器，说不清一次网页请求中间发生了什么
  - 英语：能读官方文档和教材，看视频需要字幕

## 教学偏好

- 有效的讲法：先讲"这解决什么问题"，拿具体数字走一遍，最后才给定义和符号
- 容易烦躁的：一上来堆公式；术语先给定义后讲来历；只给结论不给推导
- 例子偏好：网页请求、图像处理、机器学习里能碰到的例子

## 学习习惯

- 可投入时间：每周 3~4 次，每次 40 分钟左右
- 节奏：一个知识点一节课，学完当堂做页内练习；攒 3~5 个节点做一次阶段评估
- 常见卡点：抽象符号（矩阵、下标）容易卡住；看不见的过程（数据在网线里怎么走）需要具体化

## 跨科目观察

- 抽象符号先拿具体数字走一遍，再回头看定义，接受度高很多
- 喜欢自己动手跑一遍：跑通了再讲原理，比先讲原理再跑更有效
