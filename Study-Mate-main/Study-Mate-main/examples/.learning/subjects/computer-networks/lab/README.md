# 第 3 课 lab：自己算一个网段

**载体**：源码 + 测试。任务文件是一份留白的 Python 模块，测试文件用标准库 `ipaddress` 当对照答案。
你写的每个函数都要和标准库算得一样，包括 `/31`、`/32` 这两个容易写错的边界。

## 环境

- Python 3.8 或更高版本，`python3 --version` 能看到版本号就行
- 只用标准库：`unittest` 用来跑测试，`ipaddress` 用来当对照（测试里用，你自己实现的那份不许调它）
- 不需要装任何第三方包，也不需要联网

## 怎么跑

```bash
cd 0003-ip-subnet
python3 -m unittest -v          # 全部任务
python3 -m unittest -v test_ipcalc.TestT1Convert   # 只跑 T1 那个用例集
```

刚拿到手是**红的**：每个函数体都是 `raise NotImplementedError`，跑测试会报错退出，这是留白态该有的样子。
写完一个任务就单独跑那一组用例，绿了再往下做。

## 任务表

| 任务 | 函数 | 要做到什么 |
| --- | --- | --- |
| T1 | `ip_to_int` / `int_to_ip` | 点分十进制与 32 位整数互转；组数不对、某组不是 0~255 的十进制数时抛 `ValueError` |
| T2 | `parse_cidr` | 把 `192.168.1.100/26` 拆成地址与前缀长度；缺斜杠、前缀不在 0~32 时抛 `ValueError` |
| T3 | `network_of` / `broadcast_of` / `host_count` | 用位运算求网络地址、广播地址与可用地址个数 |
| T4 | `usable_range` | 返回可用地址的首尾；`/31` 与 `/32` 按 RFC 3021 处理，不减 2 |
| T5 | `same_subnet` / `split` | 判断两个地址是否同网段；把一个网段切成等长的子网 |

函数签名、返回类型与一个例子写在 `ipcalc.py` 每个函数的 docstring 里，测试断言的就是那些行为。

## 建议的顺序

1. 先做 T1，它不涉及子网，只是把四组数字拼成一个整数。做完跑一次 `TestT1Convert`，看到它变绿再往下
2. T2 是输入校验，重点是把「什么样的写法算非法」想全
3. T3 是核心：先把掩码写成一个 32 位整数，网络地址就是它与 IP 的按位与
4. T4 把 T3 的结果用起来，注意 `/31`、`/32` 两种地址总数不大于 2 的前缀
5. T5 里 `split` 用循环加步长就够了，别去拼字符串

## 卡壳了按这个顺序来

1. **读错误信息**：先看最后一行是 `AssertionError` 还是 `ValueError`，它指向哪个任务；`-v` 会打印出断言里那两个值
2. **自己手算一遍**：把失败用例里的地址写到纸上，按第 3 课的算法算出网络地址与可用范围，再和返回值对照，差在哪一位
3. **提示**：掩码的本质是「前 N 位是 1、后面全是 0」的 32 位整数；主机位全 0 就是网络地址，全 1 就是广播地址
4. **线索**：`ipaddress.ip_network("192.168.1.100/26", strict=False)` 能打印出标准库认为的网络地址与广播地址，用它对照单个用例的中间值——但别把它抄进 `ipcalc.py`
5. 到这一步还卡着，就把失败的那一行断言和 `ipcalc.py` 里对应的函数贴回会话

## 自查清单

- `python3 -m unittest -v` 全绿，退出码是 0
- `ip_to_int("255.255.255.255")` 返回 `4294967295`，`int_to_ip(0)` 返回 `0.0.0.0`
- `network_of("192.168.1.100/26")` 返回 `192.168.1.64`
- `usable_range("192.168.1.100/26")` 返回 `('192.168.1.65', '192.168.1.126')`
- `usable_range("10.0.0.0/31")` 两个地址都可用，`usable_range("10.0.0.1/32")` 首尾相同
- `split("192.168.1.0/24", 26)` 返回四个 `/26`，第一个是 `192.168.1.0/26`
- `ipcalc.py` 里没有 `import ipaddress`
