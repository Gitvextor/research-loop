计算机网络 Glossary

这门课讲的是「一次网页请求在网线里经过了什么」：从浏览器发出的字节，到分层封装、以太网帧、IP 转发，再到 TCP 的可靠传输与真机抓包。

两节都算这门课的规范用词：课件正文与配图用词以本文件为准。开课时先把主题词写进「待掌握」，
学生真的会用之后挪进「已掌握」——挪动本身就是一条学习记录。

待掌握

首部与载荷:
首部是本层自己要读的控制信息（地址、序号、长度等），载荷是上层交下来的全部内容。同一段字节在上一层是载荷，到下一层就变成「首部＋载荷」的一部分。
Avoid: 包头与包体、头信息与数据体

以太网帧:
链路层在一个局域网内实际传输的单元，由目的 MAC、源 MAC、类型、载荷与校验和组成；两端网卡与交换机都按这个格式读写。
Avoid: 数据帧、以太帧、packet（帧与包不是一回事）

MAC 地址:
网卡在局域网内的地址，48 位，通常写成六组十六进制数。它只在同一个局域网内用来找到下一跳，出了这个局域网就换掉了。
Avoid: 物理地址、硬件地址、网卡地址

交换机:
局域网里把多台设备连起来、按 MAC 地址把帧只转发到目标那一口的设备。它不读 IP 地址，也不关心帧里装的是网页还是视频。
Avoid: 交换器、HUB（集线器是另一种设备，所有口都转发）

MTU:
最大传输单元，一层能承载的载荷字节数上限；以太网常见值是 1500。超过它就要分片或由上层切成多段。
Avoid: 最大包长、最大帧长（帧含首部，与 MTU 不是一个数）

前缀长度:
写在斜杠后面的数字，表示 32 位 IP 地址里前多少位属于网络部分，其余位属于主机部分。它取代了 A/B/C 类地址，写法如 /26。
Avoid: 掩码长度、子网位数、网络位

子网掩码:
与前缀长度等价的一种写法：网络部分写 1、主机部分写 0，再用点分十进制表示，/26 对应 255.255.255.192。
Avoid: 掩码、netmask（与「通配符掩码」不是一回事）

默认网关:
本机路由表里那条「目标不在本网段时该交给谁」的记录，通常就是本网段路由器的地址。它必须与本机地址在同一网段，否则根本发不出去。
Avoid: 网关地址、出口路由、路由器地址

逐跳转发:
IP 包从源到目的不是一次飞过去，而是每到一个路由器就查一次表、决定下一跳，逐段接力。每一跳都换链路层首部，IP 首部除 TTL 外基本不变。
Avoid: 路由跳转、寻址、直连

TCP 三次握手:
建立 TCP 连接时双方交换三个报文，用来确认彼此的收发能力并同步初始序号。连接建立后，重传、排序与流量控制都建立在序号之上。
Avoid: 三次握手（单独用时要写明是 TCP）、SYN 握手

已掌握

协议分层:
能用「浏览器、操作系统、网卡、路由器各管一段」把一次网页请求拆开讲，并说出某一层换掉时哪一层不用改。
Avoid: 网络分层

封装:
能指出一段 HTTP 请求从浏览器到网线上依次被加上了哪几个首部，并按字节数算出多出来的开销。
Avoid: 打包、包装
