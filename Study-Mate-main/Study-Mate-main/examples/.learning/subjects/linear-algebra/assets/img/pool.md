# 线性代数 · 图片库索引

图片库目录是 `assets/img/pool/`，本文件是它的索引。课件里的 `::: figure` 按这里的文件名挑图，
题注里的「来源 / 许可」由渲染器自动读本文件的 `来源 URL` 与 `许可` 两列补上，作者不用手写。

本课目前**只用 `::: svg` 内联示意图**：张成、网格形变、零空间与三种解的情形都是几何图，用矢量
画法更清楚、离线也不糊，所以图片库暂时是空的。将来要放本机生成的位图（比如迭代轨迹的折线图），
脚本存 `assets/img/gen/`、图落本目录，再在下表登记一行：来源 URL 写「本机生成（脚本 …）」、
许可写「本项目自产」。
