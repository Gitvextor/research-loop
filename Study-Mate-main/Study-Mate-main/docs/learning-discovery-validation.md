## 真实对话的执行方式

[合成场景文件](../scripts/tests/fixtures/learning_discovery_cases.json) 固定 12 个场景的用户事实、逐轮回复条件与独立验收标准。实际使用 DSH `0.1.5-rc.3` 的学习预设、`deepseek-v4-flash`／`low`，由官方 API 执行；GPT 审查记录。合成用户由评审逐轮作答，不是真人试用，也不是同一模型自己给自己的回答打分。

1. 每次安装到独立 DSH 配置与学习目录，隔离 HOME、临时目录及预设中的绝对路径。只准备合成记忆／科目，安装完成后才记录文件基线；不读取真实学生学习数据。
2. 从 `initial_user` 开始，按当前问题选择 `adaptive_answers`，条件满足时使用 `turns`；未提供的事实回答“不确定”。不把 `checks`／`review_only` 或未问到的用户事实交给被测模型，不加纠错暗示以取得通过。
3. 保存模型消息、用户回复、问题卡片、真实工具调用及逐轮文件摘要。问题数按语义人工复核：卡片数、轮数、五项信息数都不等于实质问题数。后台角色完成后可能继续唤醒主控，以完整事件及最终文件为准，不能只看旧的等待消息。
4. 分别核对探索、开课准备、确认建课、拒绝开始、确认开始的边界。文件摘要之外检查写入与建目录的工具调用；已有科目恢复学习按原契约处理，不套用“无科目探索不得写入”。
5. 逐项标为通过、失败、未触达、未完成或未验证。达到测试轮数阈值或运行时中断保留原记录，不补跑凑通过。原角色未实际派工、未实际渲染和检查的文字承诺不能算端到端通过。

本机完整证据保存在 Git 本地排除的 `local-drafts/learning-direction-exploration/eval-results/`：每次有版本／技能摘要、事件、回复、文件快照与 `review.json`。一个运行时中断没有产生最终结果文件，另存只读外部快照并明确标记；一次缺问题卡的交接运行收到评审补发的索卡请求，仍判失败，不计无干预通过。冻结的初始优化稿及清单同样只留本地；运行适配器依赖本机 DSH 内部接口，不进入产品提交。其他环境可按 fixture 在学习界面逐轮复现。

### 首轮 12 个场景

下表为真实运行与人工语义评审，不是静态片段断言。整场判定包括适用的共用约束；例如五问专项通过，之后退出仍违规，整场仍记失败。

| 场景 | 三次整场结果 | 实际观察 |
|---|---|---|
| 明确科目／恢复学习 | 3 通过 | 线性代数直达原盘问；切换合成已有 Python 科目未被探索拦截 |

| 五问后建议 | 3 失败 | **第五问后给建议专项 3/3 通过**；后续退出未仅收尾 |
| 八问仍不足 | 3 失败 | 自然停止在 7／7／6 个实质问题；精确第八问边界均未触达；有过度补问、设备推断及退出问题 |

### 定向复测的改善与残留

- **退出专项 3/3** 均只回复“好，今天先到这里。”；零基础场景退出也如此。但记忆复用场景仍输出 109 字符摘要，所以不能声称退出已普遍修好。
- 记忆复用复测没有重问已确认偏好，正确保留每周 2 小时；零基础复测未再把时间和设备塞进同一卡。两例仍在信息已够后补细节，整场都失败。
- 交接复测实际补齐深度、具体基础、至少三个项目选项、载体和独立建课确认，未借五问省略原盘问；仍重复一次已知偏好。主动加深保留了实际累计数，仍有菜单夹问题和未经核实的时长。
- 最后格式采样采用三行模板，三个候选的主要字段齐全，菜单没有夹需求问题；报告为 **828 个 Unicode 字符／574 个汉字**（字符数含 Markdown 和菜单），仍偏长，还重复菜单、遗漏自述来源并给出未经核实的学习时长。该单样本不能用来证明稳定缩短报告。

两次首课检查仅有“下一课还未生成”的正常警告；确认前无伪造 subject／node 或知识测验。建课后仍由原 owner 写入目标、使命与大纲，正式教学题目由 `practice-evaluator` 生成。

## 限制与后续验收门槛

- 精确八问停止规则只有静态检查、人工走读及此前一次提供虚拟八问历史的独立模型响应采样；**真实 DSH 从第一问计到第八问的边界仍待验证**。该单次采样不计入 36 场，fixture 中的可选历史续接本轮未执行。
- 多问已够用的信息、未知转事实、交接来源不准、候选不齐或偏长仍未全部解决；不能仅凭静态检查通过就声明行为验收完成。后续应针对这些失败复测，而不是删断言或改答案迁就模型。
- 验证仅覆盖上述模型与 DSH 版本。网络环境阻止部分网页正文抓取，角色已记录 Gaps；没有把搜索摘要当成逐页核验。模型不支持视觉核验；人工检查整改首课配图发现裁切与连线问题，属于原教学产物质量，未扩展本次功能去修改渲染／配图链路。
- 未运行浏览器交互作答／完整视觉套件；首课通过只指实际生成和原校验。本轮不组织 5—10 人试用，尚无推荐准确率、学习收益、节省时间或就业效果的实测结论。

量化使用实际分母和适用范围：及时建议次数／触发条件次数、重复提问数／复用机会数、正确退出次数／退出请求数、异常写入次数／完整观察阶段数。无适用样本写“未覆盖”，不写 100%。本次不是与原系统的对照实验，不能用上述流程数字推算功能收益百分比。
