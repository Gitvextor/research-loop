# 课件内容格式 v1（模型只写内容，HTML 由渲染器产出）

讲解角色写**内容文件**（`<科目>/lessons/<序号>-<节点id>.md`），出题角色写**题库**
（`<科目>/lessons/<序号>-<节点id>.quiz.json`），HTML 由 `scripts/render_lesson.py` 从
`templates/lesson.html`（占位符壳）+ `<科目>/curriculum.yaml`（序号/标题/前后邻居）一次渲染出来。

```bash
python3 scripts/render_lesson.py <科目目录> <节点id>            # 写 <科目>/lessons/<序号>-<节点id>.html
python3 scripts/render_lesson.py <科目目录> <节点id> --check    # 只解析校验，不写盘
python3 scripts/check_lesson.py <科目>/lessons/<序号>-<节点id>.html --subject <科目目录> --node <节点id>
```

退出码：`0` 通过；`1` 有问题（逐条打印 `<文件>:<行> <问题>`）；用法错误 `2`。

**核心约定：模型一个字 HTML 都不写。** 渲染器产出 head 与共享层引用、顶栏、页头（eyebrow =
`序号 · 标题`）、提问提示、上/下节课指针（按 `curriculum.yaml` 的 `nodes:` 顺序算，第一课无
`--prev`、最后一课无 `--next`）、页脚、脚本，以及正文里所有组件 HTML（完整清单见第 5 节）。内容文件里
出现块级 HTML 标签（`<div>`、`<figure>`、`<p>`…）会被**当成错误拦下**——这是渲染器的判定，不是风格建议。

**一条铁律：认不出就报错。** 未知指令、认不出的块语法、锚点在题库里没题又没写 `empty_reason:`、
题库里多出来的锚点、内容里没有题目位置却留着题库文件、同一个锚点被两个题目位置引用、配图文件不存在、
模板缺占位符，全部带行号报错，绝不静默降级或丢内容。

## 1. front matter（必填，文件开头）

```markdown
---
title: 分支与循环
goal: 能用 `if`/`else` 把一段判断流程写完整，并让等于分档线的取值落在你定下的那一档。
---
```

| 字段 | 规则 | 落到页面哪里 |
|---|---|---|
| `title` | 必填，**纯文本**，建议 ≤16 字（超了渲染器打一行提示）；**必须与 `curriculum.yaml` 里该节点的 `title` 逐字一致**（不一致渲染器按行号报错） | `<title>`、`<h1>`、页头 eyebrow 的 `序号 · 标题`、页脚 |
| `goal` | 必填，一句话，**支持行内语法** | `.lesson-goal` 里「本节目标：」后面 |

只有这两个字段，写别的字段报错。**这节课叫什么只有一个答案**：front matter 的 `title` 与
`curriculum.yaml` 节点的 `title` 逐字一致——页面 `<title>`／`<h1>`／eyebrow 用前者的，主页卡片与
路线图用后者的，不一致就是同一节课挂了两个名字（渲染器带行号报错，指出两个名字各是什么）。
上/下节课指针与文件名序号**不在 front matter 里**：它们从 `curriculum.yaml` 算（抄了会漂移）。

## 2. 块语法

| 写法 | 渲染结果 | 备注 |
|---|---|---|
| `## 标题` | `<h2>` | 会进左侧目录；检查对 >14 字的标 WARN（不阻断） |
| `### 标题` | `<h3>` | 四级及以下标题报错 |
| 空行分隔的段落 | `<p>` | 段内换行：两侧都是中文就直接相接，否则按一个空格接 |
| `- 项` | `<ul><li>` | 只有 `-`；`* `/`+ ` 报错 |
| `1. 项` | `<ol><li>` | 序号写什么都行，渲染成 `<ol>` 的自然序号 |
| 缩进 2 格的行 | 上一层最后一项的子列表 | 只允许 2 格；其他缩进报错 |
| ` ```lang ` … ` ``` ` | `<pre data-lang="lang"><code>转义后的原文</code></pre>` | 缺语言就不写 `data-lang`（不上色）；原文逐字保留（含缩进与空行） |
| 管道表（第二行分隔行） | `<table><thead>…<tbody>…` | 见下 |
| `::: <指令>` … `:::` | 见第 4 节 | 每个指令块都要有单独的 `:::` 收尾行 |
| 其他 | **报错** | `> ` 引用块、`---` 分隔线、缩进的块级内容都报错 |

**只有 `##` 与 `###`**：`# 一级标题` 与 `####` 及以下都报错。小心**行首的 `#`**——`#include <cstdio>`、
`#define N 100` 顶格写会被当成标题标记；渲染器会说明「这一行被当成一级标题」，把这类代码**放进 ``` 围栏**
就好（围栏里逐字保留，`#` 不起作用）。

段落里可以任意写 `<`、`>`、`&`（例如 `a < b && c > d`），渲染器转义成 `&lt;` / `&gt;` / `&amp;`，
不用也不许自己写实体。**但真标签不许写**：`<b>粗</b>`、`</div>`、`<img src=…>`、`<iframe>`、
`<video>`、`<form>`、`<main>` 在正文任何位置（段落、标题、列表项、表格单元格、`alt:`/`caption:`、
front matter 的 title）都会报错——它只会原样显示成 `&lt;b&gt;`，学生看到的是乱码一样的字面量。

判据两条，**缺一不可**（这样运算符与泛型不会被误杀）：

1. `<` 前面**不是 ASCII 字母或数字**——`n<m`、`a<b>c`、`std::vector<int>` 是运算符/泛型，放行；
2. 名字在**真标签白名单**里——**完整标准 HTML 元素表**（HTML living standard 的每一个元素：含
   aside、iframe、video、form、main、button、canvas 这类正文元素，也含 center、font、marquee
   这类旧式、表现型与已废弃元素）**加上 SVG 元素名**（标签名统一转小写再查表，所以这里一律小写）：

   `a abbr acronym address animate animatemotion animatetransform applet area article aside audio b
   base basefont bdi bdo bgsound big blink blockquote body br button canvas caption center circle
   cite clippath code col colgroup content data datalist dd defs del desc details dfn dialog dir
   div dl dt ellipse em embed feblend fecolormatrix fecomponenttransfer fecomposite
   feconvolvematrix fediffuselighting fedisplacementmap fedistantlight fedropshadow feflood fefunca
   fefuncb fefuncg fefuncr fegaussianblur feimage femerge femergenode femorphology fencedframe
   feoffset fepointlight fespecularlighting fespotlight fetile feturbulence fieldset figcaption
   figure filter font footer foreignobject form frame frameset g geolocation h1 h2 h3 h4 h5 h6 head
   header hgroup hr html i iframe image img input ins isindex kbd keygen label legend li line
   lineargradient link listing main map mark marker marquee mask math menu menuitem meta metadata
   meter mpath multicol nav nextid nobr noembed noframes noscript object ol optgroup option output
   p param path pattern picture plaintext polygon polyline pre progress q radialgradient rb rect rp
   rt rtc ruby s samp script search section select selectedcontent set shadow slot small source
   spacer span stop strike strong style sub summary sup svg switch symbol table tbody td template
   text textarea textpath tfoot th thead time title tr track tspan tt u ul use var video view wbr
   xmp`

   这些引擎自己的组件与语料真会用到的标签全在里面；`<T>`、`<m>` 不是标签，放行。

   名单的唯一载体是 `scripts/render_lesson.py` 的 `HTML_TAG_NAMES`（比较前 `lower()`），本节是它的
   镜像，测试断言「代码 = 本节 = 测试里的字面集合」三者逐字一致、且范围是**完整**标准 HTML 元素表 +
   SVG 元素名（不是"常用子集"）。改名单时三处同步。

   加名字**只对「名字形状」合法的标签有效**：判据正则捕获的是 `[a-zA-Z][a-zA-Z0-9]*`，**不含连字符**
   ——`<syo-editor>` 这类自定义元素加多少名字都匹配不上，照样当字面量出厂；要加这类组件就**做成
   `:::` 指令**（第 7 节）。

   名单收的是**元素名**：MathML 内层元素名（`<mrow>`、`<mi>` 这类）**不在**名单里，写进正文会被当普通
   文字放行——数学式写 `$…$` / `$$…$$`（第 3 节），示意图写 `::: svg`。

`a < b`、`x > 0`、`2 < n`、`<T>` 都是普通文字；要写代码或泛型这类字面量，用反引号包起来
（`` `vector<int>` ``），那是 `<code>` 不是标签。**反引号要成对**：落单的反引号是普通字符、
不开启 code 区（所以它也遮不住后面的标签）。要在页面里**展示** HTML 本身，把那段放进 ``` 围栏
（短片段也可以用反引号，如 `` `<b>` ``）——内容文件写的是教学内容，不是标记。

**HTML 注释也不许写**：`<!-- 题目位置：L1 ×2 -->` 这类是手写时代留题目位置的写法，现在题目位置写
`::: quiz <层级> 锚点：…`，说明直接写进正文。

### 管道表

```markdown
| 题面里的说法 | 写法 | 等于分档线时 |
| --- | --- | --- |
| 不足 100 元 | `amount < 100` | 落入下一档（收 4 元） |
```

- 第一行是表头，**第二行必须是分隔行**（`| --- |`、`|:---|` 都行），第三行起是数据行。
- 分隔行的**格子数必须与表头一致**，且每格都要是 `---` 形状（`| --- | |` 报错：那一格是空的）。
- 每行的格数必须与表头一致，不一致报错并指出行号。
- 单元格里要写字面竖线（C++ 的 `||`）写成 `\|`；单元格里支持全部行内语法。

## 3. 行内语法

| 写法 | 渲染结果 | 备注 |
|---|---|---|
| `` `代码` `` | `<code>代码</code>` | `&<>` 转义；`*`、`**` 是字面量（`` `int **p` `` 不会被当粗体） |
| `**粗**` | `<b>粗</b>` | 可以套别的行内语法 |
| `*斜*` | `<em>斜</em>` | 星号里侧不能紧挨空格（`10 * 20` 不会误判） |
| `[文字](href)` | `<a href="href">文字</a>` | href 转义；外链不加 `target`，统一成裸链接 |
| `^x^` | `<sup>x</sup>` | 内容不能带空格、不能再有 `^`；`2^31^` → `2<sup>31</sup>` |
| `~x~` | `<sub>x</sub>` | 同上；`a~n~` → `a<sub>n</sub>` |
| `$TeX$` | 行内公式（KaTeX 排版） | 开 `$` 后、收 `$` 前都不能是空白，中间不跨行；见下 |
| `$$TeX$$` | 块级公式（整段只有它时） | 居中、独立成行；矩阵与多行推导用这个 |

落单的标记当普通字符（`10 ~ 20`、`a ^ b`、`int **p` 都不会误判、也不报错）。

### 数学式（`$…$` 行内 / `$$…$$` 块级）

写 **TeX**，排版由渲染器注入的**离线 KaTeX** 在浏览器里完成（共享层 `assets/katex/` +
`assets/lesson-math.js`，不联网、无 CDN）：

```markdown
解 $Ax = b$ 就是把 $b$ 写成 $A$ 的列向量的线性组合。消元后：

$$
\begin{bmatrix} 2 & 1 \\ 1 & 3 \end{bmatrix}
\begin{bmatrix} x \\ y \end{bmatrix}
=
\begin{bmatrix} 9 \\ 10 \end{bmatrix}
$$
```

- **方程组要带大括号**（不写就没有，KaTeX 不会自己加）。**两种写法都行**，看你要不要对齐等号：

  ```markdown
  $$
  \begin{cases}
  x + y + z = 4 \\
  2x + 2y + 2z = 8 \\
  x - y = 0
  \end{cases}
  \qquad\text{或}\qquad
  \left\{\begin{aligned}
  x + y + z &= 4 \\
  2x + 2y + 2z &= 8 \\
  x - y &= 0
  \end{aligned}\right.
  $$
  ```

  `cases` 行左对齐、写得省事；`aligned` 能把等号对齐、长式子更好读。别省括号才是要点——
  一列等式没有括号，读者第一眼会当成几个独立结论，而不是同一个方程组的几个方程。
- **判据**：开 `$` 后面紧跟非空白、收 `$` 前面也是非空白、中间非空且不跨行——所以散文里的
  价格写法不会误判（`花了 $5 和 $10` 里两个 `$` 的收尾判据不成立，按字面量处理）。
- **没收尾会报错**（`行内公式 $…$ 没有收尾`）：公式写错时页面会显示 TeX 原文，那是看不出错的，
  所以按确定性错误拦下。正文里真要写美元号，写成 `\$`。
- **代码里的 `$` 不受影响**：代码围栏与行内代码（`` `$HOME` ``）里的美元号照原样进代码块。
- **题面里也能写公式**：题库（`.quiz.json`）的题面/选项/参考答案/判分要点/解析都是纯文本字段，
  里面的 `$…$` 由页面里的 `quiz.js` 交给同一个 KaTeX 排版（判据与正文一致；`\$` 是字面美元号，
  ``` 围栏里的 `$` 不算公式）。**公式只出现在题面里时，渲染器照样会注入 KaTeX**——不用为此
  在正文里凑一个公式。
- **没有数学式的页面不加载 KaTeX**：渲染器只在正文出现 `$…$` / `$$…$$`、或题库里带公式时注入那三个
  引用，非数学课与老课件的产物零变化（检查项 11 按这条条件判定）。
- **KaTeX 没加载成功时降级可读**：元素里先放着 TeX 原文，`lesson-math.js` 加载后才替换成排版结果。
- 编号、来源、题注这些**可推导的信息一律别手写**（图注编号由渲染器给，见第 4 节）。

**上下标写在代码里**：代码 span 里 `^x^` / `~x~` **照样解析**（判据与正文一致——内容不带空格、不重复
同种标记），所以 `` `~a & ~b` ``、`` `a ^ b` ``、`` `int **p` `` 都不会误判。

## 4. `:::` 指令（块级组件）

每个指令都以单独一行 `:::` 收尾；**指令块不能嵌套**（嵌套报错）。指令名只有下面这些，写别的报错。

### `::: practice <层级> | <标题>` —— 练习块

```markdown
::: practice 练习 | 第 1 步 · 三条路各跑一次

把上面这段存成 `main.cpp`，换三个输入各跑一次。

```term
$ echo 600 | ./main
超出单笔限额 500，请分次取
```

:::
```

产 `<div class="lesson-practice">` + `__head` 里的 `__level`/`__title` 两个 span，块里可以是任意
块（段落、列表、代码围栏、表格）。层级是内容元信息（写 `练习`／`上手做` 这类中文阶段名），原样落到
`__level` 里显示成**徽标**；标题按内容写（如「第 3 步 · 改造」），**不写 L1-L4**。

### `::: quiz <层级> 锚点：<锚点文本>` —— 题目位置

```markdown
::: quiz 理解 锚点：悬垂 else 的归属
:::
```

- 题目**不在内容文件里**：渲染器拿锚点文本去 `.quiz.json`（结构 `{"锚点文本": [题, …]}`）里取，
  逐字匹配，产出 `<div class="quiz" data-quiz='…'></div>`，字段契约见 `templates/assets/quiz.js`。
- **题面里可以写数学式**：`$…$`（行内）由 `quiz.js` 在页面上排版，判据见第 3 节的「数学式」；
  矩阵题、方程组题都直接写 LaTeX，别用空格对齐的 ASCII 去凑。
- 属性值由渲染器转义：单引号包裹，值里 `&`/`<`/`>`/`'` 写成实体，JSON 字符串内部的引号走 JSON 的
  `\"`——作者不需要知道这些。
- 锚点在题库里没题时，**必须**补一行理由，否则报错：

  ```markdown
  ::: quiz 应用 锚点：分档数组版
  empty_reason: 该锚点要验的东西在 lab 里，本轮不出题
  :::
  ```

- 层级（理解/改造/排错/应用）与锚点文本都不进页面：层级给出题角色与评审看；锚点是两个文件之间
  的唯一接头。锚点写错（题库里没有）＝报错，不会静默少一道题。
- 反方向也报错：题库里**多出来的锚点**（没有任何题目位置引用它）＝报错——删掉那个键，或让讲解角色在
  正文里补题目位置。**内容里一个题目位置都没有、`.quiz.json` 却还在**同样报错；反过来，没有题目位置也
  **不需要**题库文件（`kind: 实验` 的说明页就是这样，只有 `.md` + `.html` 两件）。
- 同一个锚点被**两个题目位置**引用也报错：同一批题会被渲染两遍（一个锚点只留一个题目位置）。
- 锚点有题却写了 `empty_reason:` 也报错（那是给无题锚点用的）。

### `::: figure <相对路径>` + `alt:` / `caption:`

```markdown
::: figure ../assets/img/pool/数组-内存布局-连续存储-cppreference-01.png
alt: 连续存储
caption: 数组在内存里挨着放
:::
```

- 路径按课件目录（`lessons/`）解析，文件不存在**报错**；不接受外链（图从科目图片库
  `assets/img/pool/` 里挑，索引是 `assets/img/pool.md`）。
- `alt:` 必填（裂图时读屏软件与学生都只剩空白）；`caption:` 可选。`alt:` 落进 `alt` 属性，是
  **纯文本**（不解析 `**`/反引号这类行内标记），但和 `caption:` 一样**不许真标签**——它会转义成
  `&lt;b&gt;` 让学生听到乱码，所以按报错拦下（`::: svg` 的 `alt:` 同一条规则）。
- `caption:` 只写**一句话描述**，**编号由渲染器加**（页内出现顺序，`::: figure` 与 `::: svg`
  共用一条序列，输出形如「图 1 · 数组在内存里挨着放」）。编号是可推导的信息，手写必然漂移：
  旧课件里已经写了「图 N ·」的，渲染器会**剥掉旧号重编**——所以重渲染是幂等的，老写法不改也不会重号。
  反过来，正文里若写了「见图 N」这类交叉引用，在中间插一张图会让后面的编号整体后移，改完要对一遍。
- 没写 `caption:` 的图**不编号**（没有可见标签就不占号，学生不会看到跳号）。
- 图在图片库里时渲染器**自动补**「（来源：…，许可：…）」（来源 URL 与许可读 `pool.md` 那一行），
  作者不用手写来源。`许可` 填「未标注」是常见且可接受的（个人学习用途，标注来源即可，采图角色不逐张核许可）。

### `::: svg` + 可选 `alt:` / `caption:`

```markdown
::: svg
alt: 双指针向中间收拢
caption: 收拢过程

<svg viewBox="0 0 40 20" role="img" aria-hidden="true"><path d="M2 10h36" stroke="currentColor"/></svg>
:::
```

`caption:` 与 `::: figure` 同一套写法：只写描述，编号由渲染器按页内顺序加（两者共用一条序列）。
产 `<figure class="lesson-figure lesson-figure--inline">`，块内 SVG **原样透传**（不转义、不改写；
线条用 `currentColor` 才会跟着主题走）。写了 `alt:` 会写成 `role="img" aria-label="…"`。
这是唯一允许写标签的地方——它画的就是标签本身。块里必须有 `<svg…>`，并且要有收尾：
`</svg>` 或自闭合的 `<svg/>`（缺收尾报错，因为原样透传会从那里把页面结构断掉）。

:::
```

分别产 `<div class="lesson-tip">` / `lesson-warn` / `lesson-note`，标题写成块首的 `<b>`（可省略）。
`note` 是中性提示卡，样式与 tip/warn 同一族。

### `::: resources` / `::: related`

```markdown
::: resources
- [OI Wiki · 分支](https://oi-wiki.org/lang/branch/) | 官方文档 · if 与 else if 的写法
- Competitive Programming 4（Halim 等，第 4 版） | 书 · 第 4 版；当参考书查
:::

::: related
- [上节课：浮点与精度](0004-cpp.float.html)
:::
```

`resources` 产 `<ul class="lesson-resources">`，每条两种写法：`- [标题](链接) | 说明`（说明可选，
写成 `<span class="lesson-resources__meta">`）或 `- 标题 | 说明`（**没有链接**的条目，例如一本书、
一份本地文档）；`related` 产 `<div class="lesson-related">`，每条只写 `- [标题](链接)`（相关课件
必须给得出来链接）。

## 5. 渲染器自己产出的部分（模型不写）

- head：字符集、viewport、`<title>标题 · 科目名</title>`、共享层三条样式（`../../../assets/sayo/sayo.css`、
  `learn-theme.css`）+ 科目组件（`../assets/style.css`）、`learn-theme.js` 与 `LearnTheme.apply()`。
- 顶栏 `.lesson-bar`：返回课程、科目名、编号、主题开关（`id="lesson-theme-checkbox"`）。
- 页头 `.lesson-header`：eyebrow（`序号 · 标题`）、`<h1>`、`.lesson-goal`。
- 正文（本文件的块与行内语法）。
- `.lesson-ask`（固定的提问提示）。
- `.lesson-nav`：上/下节课指针，href 是 `NNNN-<节点id>.html`，标题取 `curriculum.yaml` 的 `title`。
- `.lesson-footer`、三个 `<script>`（`sayo.js`、`quiz.js`、`lesson-toc.js`）与 `LearnTheme.wire(...)`。

模板占位符（`templates/lesson.html`，约定与 `gen_home.py` 一致）：
`<!-- @LEARN:TITLE -->`（`<title>` 与 `<h1>` 两处）、`SUBJECT`（两处）、`NUMBER`、`EYEBROW`、
`GOAL`、`BODY`、`NAV`、`FOOTER`。缺任何一个都报错，防止模板被改坏后静默产出残缺页面。

模板开头那段写给维护者的说明注释**留在 `<!DOCTYPE html>` 之前**，渲染器只从 `<!DOCTYPE` 起取内容，
所以它不随课件出厂——学生查看页面源码时读不到写给模型的说明。

成功（退出码 0）时 stderr 上仍可能有 `提示: …` 开头的行（标题超过 16 字、锚点按 `empty_reason`
跳过这类软提醒）；**退出码只看有没有 `<文件>:<行>` 的问题行**，提示不代表失败。

## 6. 反例（这些都会带行号报错）

```markdown
# 一级标题                     → 只有 ## 与 ###（行首 #include / #define 也一样，代码放围栏）
#### 四级标题                  → 标题只支持 ## 与 ###
> 引用一段                    → 认不出的块语法（引用块本格式不支持）
- 项一
    - 缩进 4 格               → 列表嵌套只缩进 2 空格
<div class="lesson-tip">…</div> → 内容文件不写 HTML（用 ::: tip）
这段手写了 <b>粗</b> 标签       → 正文里不许有真标签（粗体写 **粗**）
见 ` 这里 <b>粗</b> 结束        → 落单的反引号不是 code 区，遮不住标签（照报）
前面 <!-- 题目位置：L1 ×2 --> 后面 → 内容文件不写 HTML 注释（题目位置写 ::: quiz）
title: <b>粗</b>标题           → front matter 的 title 也是散文，同样不写标签
::: fancy 标题                 → 未知指令 ::: fancy
::: tip 忘了闭合               → 指令 ::: tip 没有闭合
::: quiz 理解 锚点：写错的锚点  → 锚点「写错的锚点」在题库里没有题（补题或写 empty_reason:）
::: figure ../assets/img/pool/没有的图.png → 图片文件不存在（解析到 …）
::: svg                        → 块里没有 <svg>…</svg> 原文 / <svg> 缺 </svg> 收尾
::: svg 块里收尾拆成两行 </sv + g> → 收尾按行拼起来判，拆开就不算闭合（多行开标签仍放行）
<iframe src="…"></iframe>       → iframe / video / form / main / button / canvas 全都拦（真标签全表）
::: figure … 的 alt: <b>粗</b>   → alt: 是属性值（纯文本），但和 caption: 一样真标签也拦（行号指到 alt:）
| 只有表头 |                  → 表格第二行必须是分隔行
| a | b |
| --- | --- | --- |
| 少一格 |                   → 表格这一行有 1 格，表头是 2 格
| a | b |
| --- | |                     → 分隔行每格都要是 ---（那一格是空的）
| a | b |
| --- |                       → 表格分隔行有 1 格，表头是 2 格
---                           → 内容格式没有分隔线
```

**不算错的写法**（同样的字符，含义不同）：`a < b && c > d`、`n<m 且 m>0`、`a<b>c`（运算符，
`<` 前面是字母/数字）、`<T>`（名字不在真标签白名单里）、`` `vector<int>` `` / `` `<climits>` ``
（反引号里是字面量，且反引号成对）、`` `~a & ~b` ``（code span 里 `~` 不当标记）、
围栏里的 `#include <cstdio>`（代码块逐字保留）、`::: svg` 里自闭合的 `<svg/>`。

## 7. 已知边界（有意为之）

- **不做的事**：图片外链、HR／引用块／脚注／任务列表／表格对齐语法——真要用先扩展词汇（渲染器 + 测试 +
  本文档），不要在内容文件里手写 HTML 绕过去。
- **连字符组件**（`<syo-editor>` 这类）不在词汇里：要加就走上面同一条扩展流程，把它做成 `:::` 指令。
- **数学式走 `$…$` / `$$…$$`**（第 3 节），不写 MathML：MathML 内层元素名不在名单里，手写 `<math>` 会被当真标签拦下。`::: svg` 留给示意图（结构图、流程图、几何图形），不用来排公式。
- **代码 span 里的 `*`/`**` 是字面量，`^x^`/`~x~` 解析**：`int **p` 这类指针写法在竞赛代码里太常见，
  而 `<sup>` 要能写在代码里。
- **外链不加 `target="_blank" rel="noopener"`**：统一成裸链接。
- **`data-quiz` 的 JSON 统一 `indent=2`**：解码后的题目内容与手写一致，只是源码排版不同。
- **两个指令的层级去处不同**：`::: quiz` 的层级是元信息、**不进页面**；`::: practice` 的层级**会显示
  成徽标**（`__level`，样式在 `templates/assets/style.css`），所以写中文阶段名、不写 L1-L4（第 4 节）。
- **h2 ≤14 字、选项长度差 ≤4** 这类质量线由 `check_lesson.py` 出 WARN；渲染器不复刻这些判断。
