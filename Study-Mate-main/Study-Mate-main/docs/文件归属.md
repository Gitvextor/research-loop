# 文件归属（代称 ↔ 路径 ↔ 维护者）

**这份表是文件「代称、功能、路径、维护者」的唯一出处。** 角色规格（`.dsh/skills/*/SKILL.md`）在正文里用「代称」指代文件，不再反复写全路径；要判断自己有没有权改某份文件，查这张表的「维护者」一列。

## 怎么用

- 代称在 SKILL 正文里写作「共享记忆」这样用「」框住；本表第一列写裸名
- **角色也有代称**（见下节）：正文里可以直接用「总控」「讲解」这类叫法；**「维护者」一列写的是技能名**，按角色代称表对应
- **路径前缀**：`<root>` = 引擎仓库根；`<LEARN_WORKSPACE>` = 学习工作区；`<subject_path>` = `<LEARN_WORKSPACE>/.learning/subjects/<slug>`
- 本表**不重复**各角色的边界正文：边界仍写在各自规格里，只是可以改用代称
- **收录范围**：① 角色与协议规格正文里会提到的文件；② 学生或维护者要用的仓库入口（安装说明、工程约束、本表）。**不收纯开发工具**（发布、打包、预览脚本一类）

## 角色代称

角色（谁在干活）也有代称，正文里可以直接用。**「派工时给的值」一列是总控派工的唯一出处**——各角色规格的「输入」节只说这些值怎么用，不再重复列；本表其余各节的「维护者」写的是技能名。

| 代称 | 技能名 | 一句话职责 | 派工时给的值 |
| ---- | ------ | ---------- | ------------ |
| 总控 | `learning-system` | 开场、盘问、调度、档案；唯一有用户通道的角色（学生只跟你说话） | —（亲自做，不派自己） |
| 资料收集 | `resource-scout` | 收集权威教材与官方核对来源，产「资源清单」 | `subject_path` + 盘问结果 + `<root>` |
| 采图 | `image-scout` | 抓网页现成的位图，落「图片库」与「图片库索引」 | 「资源清单」绝对路径 + 点名要抓的条目 +（可选）额外允许站点 |
| 课设 | `curriculum-designer` | 产「课程大纲」与实验课节点 | `subject_path` + 盘问结果摘要 + 「资源清单」路径 |
| 讲解 | `learning-coach` | 写「课件内容文件」与「速查页」；配图规范的 owner | `subject_path` + 节点 id |
| 出题评估 | `practice-evaluator` | 题目唯一 owner：出题、判分、写「评估记录」 | `subject_path` + 节点 id + 「课件内容文件」路径 + 载体（**时机二**另加作答原文） |

## 一、工作区 · 共享与科目元数据

| 代称     | 文件名                | 功能                                                         | 相对路径                                | 维护者                                                  |
| -------- | --------------------- | ------------------------------------------------------------ | --------------------------------------- | --------------------------------------------------------- |
| 共享记忆 | `MEMORY.md`           | 记忆信息：用户是谁／教学偏好／用户学习习惯／跨科目观察       | `<LEARN_WORKSPACE>/.learning/MEMORY.md` | `learning-system`                                         |
| 科目使命 | `MISSION.md`          | 为什么学、学成什么样、约束与不学的范围                       | `<subject_path>/MISSION.md`             | `learning-system`                                         |
| 资源清单 | `RESOURCES.md`        | 延伸阅读与官方核对来源，每条一行用途                         | `<subject_path>/RESOURCES.md`           | `resource-scout`（初次清单）／`learning-system`（小增量） |
| 术语表   | `GLOSSARY.md`         | `## 待掌握` 与 `## 已掌握`；正文与配图用词以此为准           | `<subject_path>/GLOSSARY.md`            | `learning-system`                                         |
| 科目档案 | `subject.yaml`        | 科目名、状态、目标、创建日期（过 `subject.schema.json`）     | `<subject_path>/subject.yaml`           | `learning-system`                                         |
| 课程大纲 | `curriculum.yaml`     | 节点 DAG、`kind`、`objective`（过 `curriculum.schema.json`） | `<subject_path>/curriculum.yaml`        | `curriculum-designer`（草稿）／`learning-system`（写盘）  |
| 学习进度 | `progress.yaml`       | 运行期状态、掌握度、误解（过 `progress.schema.json`）        | `<subject_path>/progress.yaml`          | `learning-system`                                         |
| 误解库   | `misconceptions.yaml` | 误解条目（与「学习进度」的 `misconceptions` 双落点）         | `<subject_path>/misconceptions.yaml`    | `learning-system`                                         |

## 二、工作区 · 课件与素材

| 代称         | 文件名                                                 | 功能                                                                           | 相对路径                                           | 维护者                                                                           |
| ------------ | ------------------------------------------------------ | ------------------------------------------------------------------------------ | -------------------------------------------------- | -------------------------------------------------------------------------------- |
| 课件内容文件 | `<序号>-<节点id>.md`                                   | 讲解、练习引入、配图、题目位置（`::: quiz` 锚点）；`kind: 实验` 的说明页也是它 | `<subject_path>/lessons/<序号>-<节点id>.md`        | `learning-coach`（实验说明页由 `practice-evaluator` 交、`learning-system` 搬入） |
| 练习题库     | `<序号>-<节点id>.quiz.json`                            | 键与内容文件的锚点逐字对应                                                     | `<subject_path>/lessons/<序号>-<节点id>.quiz.json` | `practice-evaluator`（落 `deliver/`）／`learning-system`（搬入）                 |
| 课件页面     | `<序号>-<节点id>.html`                                 | 学生看的渲染产物，谁也不手改                                                   | `<subject_path>/lessons/<序号>-<节点id>.html`      | `scripts/render_lesson.py` 生成（`learning-system` 跑）                          |
| 速查页       | `reference/*.html`                                     | 手写 HTML 速查页（渲染器不吃它）                                               | `<subject_path>/reference/`                        | `learning-coach`                                                                 |
| 科目组件     | `assets/` 下的 `style.css`／`quiz.js`／`lesson-toc.js` | 共享层在科目里的副本，与 `<root>/templates/assets/` 同步                       | `<subject_path>/assets/`                           | `learning-system`（从「页面模板」覆盖，科目自加的组件不动）                      |
| 图片库       | `assets/img/pool/` 下的图                              | 采集来的图与自产的图，同一处存放                                               | `<subject_path>/assets/img/pool/`                  | `image-scout`（采集）／`learning-coach`（自产）                                  |
| 图片库索引   | `pool.md`                                              | 七列表头 + 每张一行 + 末尾 `## Gaps`；课件按它检索                             | `<subject_path>/assets/img/pool.md`                | `image-scout`（采集行）／`learning-coach`（自产行，只追加自己那行）              |
| 产图脚本     | `assets/img/gen/<同名>.py`                             | 自产图的可复现脚本                                                             | `<subject_path>/assets/img/gen/`                   | `learning-coach`                                                                 |
| 实操任务     | `lab/NNNN-主题/`                                       | 留白任务与断言（学生动手的地方）                                               | `<subject_path>/lab/`                              | `practice-evaluator`（落 `deliver/`）／`learning-system`（搬入）                 |
| 实操答案     | `lab/solutions/NNNN-主题/`                             | 参考解，与任务分开放                                                           | `<subject_path>/lab/solutions/`                    | `practice-evaluator`                                                             |
| lab 说明     | `lab/README.md`                                        | 载体与环境依赖、任务表、卡壳顺序                                               | `<subject_path>/lab/README.md`                     | `learning-system`                                                                |
