# 安装与更新

DSH 使用 `npx`；Codex 下载 ZIP 后导入。两种安装方式使用同版本的课件引擎，学习数据保存在独立工作区。

## DSH

需要 DSH 0.1.5-rc.2 及以上、Node.js 22.19+（22 系列）或 24+、Python 3.9+ 和 PyYAML。完整课件校验还需要 jsonschema。

Python 不自带 PyYAML。依赖安装命令应在系统终端（CMD / PowerShell / Terminal）中运行；若看到 Python 的 `>>>`，先输入 `exit()` 回到终端。请复制安装器给出的命令，使用它检测到的同一个解释器。下面以 `python` 为例；提示为 `python3` 或 `py -3` 时，相应替换：

```sh
python -m pip install PyYAML jsonschema
```

若提示 `No module named pip`，先运行 `python -m ensurepip --upgrade`（同样替换解释器命令），再重试依赖安装。完成后重试原 `npx` 安装命令，并保留原有参数（如 `--workspace`）。

macOS、Linux 和 Windows 使用同一条安装命令：

```sh
npx -y @yunmiao/studymate@latest install
dsh web
```

启动后新建会话，选择「学习模式」。**更新时再运行同一条 `npx` 命令，然后重启 DSH 并新建会话。** 旧版通过源码安装的用户也使用此命令，已有工作区配置会沿用。

默认学习工作区是 `~/StudyMate`，已有配置优先。可以指定其他目录：

```sh
npx -y @yunmiao/studymate@latest install --workspace "D:/StudyMate-workspace"
```

指定目录只改变后续读写的位置，不会自动搬迁原有学习数据。换目录或换机器时，先复制整个学习工作区（包括隐藏的 `.learning/`），再安装并指定复制后的路径。

引擎安装到 `~/.dsh/studymate/engine/`，配置保存在 `~/.dsh/studymate-config.yaml`；设置了 `DSH_HOME` 时使用对应目录。安装器按 DSH 版本注册学习预设，不会升级 DSH。升级或降级 DSH 后重新运行安装命令即可适配。

默认供 `dsh web` 使用。使用其他已创建的 profile 时加上 `--profile <名称>`，例如：

```sh
npx -y @yunmiao/studymate@latest install --profile headless
```

## Codex / ChatGPT Work

1. 从 [最新 Release](https://github.com/Miaotofu01/Study-Mate/releases/latest) 下载 **studymate-openai.zip**。
2. 通过 Codex 客户端提供的插件导入入口安装该 ZIP；没有导入入口时，按 [导入说明](Codex与ChatGPT.md) 使用插件创建器。
3. 新建任务，选择 StudyMate 的 `learning-system` 技能，并说明学习目标和工作区路径。

**更新时下载最新 ZIP，在浏览器中打开已有插件的链接，选择上传新版本，然后新建任务。** 保留原学习工作区即可继续学习。

Python 依赖、ChatGPT Work 的使用条件和工作区说明见 [Codex 与 ChatGPT](Codex与ChatGPT.md)。
